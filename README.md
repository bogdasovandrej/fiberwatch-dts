# FiberWatch

Решение кейса МГТС «Анализ данных распределённых волоконных сенсоров».

**Что делает.** Превращает профили температуры вдоль оптоволокна (CSV прибора) в короткий список событий для оператора:

```
26.05 15:11 UTC — 105,8–112,7 м — нагрев на 10,2 °C, держится до конца записи — требуется проверка
```

Работает в два этапа.

1. **Есть ли событие.** Свёрточная нейросеть смотрит на 40 минут истории в 9 соседних точках волокна и решает, похоже ли это на событие: настоящий нагрев захватывает соседние точки, а шум и сбой прибора — обычно одну. Правило решает, достаточно ли изменение велико: не меньше 3 °C и от начала окна, и от обычного фона до него. Уведомление — только когда «да» на оба вопроса.
2. **Какое это событие.** По сырым замерам относительно обычного фона: тип (нагрев, охлаждение, краткий выброс) и класс — длительность, протяжённость, повтор на том же месте и периодичность, одновременность на нескольких участках, пульсация.

Отдельно выдаёт:

- сообщения о качестве данных — недостоверные значения, разрывы, сбои измерения, сдвиги всего волокна прибором;
- прогноз: через сколько минут растущее изменение превысит порог;
- нагревы, движущиеся вдоль волокна, со скоростью и направлением.

Координаты — метры вдоль волокна.

**Качество** — на приборе, которого модель не видела:

| | CNN время × координата | Случайный лес | Правило «отклонение ≥ порога» |
|---|---:|---:|---:|
| Искусственные события: найдено из 3 024 | **2 998** | 2 996 | 2 810 |
| Искусственные события: верных среди тревог | **94,3 %** | 69,5 % | 78,5 % |
| Тревоги на одноточечных сбоях | **2,0 %** | 98,0 % | 68,1 % |
| Реальные данные: верных уведомлений | **81 из 81 (100 %)** | 85 из 87 (97,7 %) | 77 из 78 (98,7 %) |
| Уведомлений в час на всё волокно (приборы 2, 3, 4, 6) | 0,2–0,7 | 0,2–0,7 | 0,2–0,8 |

На искусственных событиях при одинаковом числе ложных тревог (181) нейросеть находит 2 998 событий, лес — 2 227: лес выглядит близко только потому, что тревожит в 7 раз чаще.

Для сравнения: **правило** — событие, если медиана температуры отклонилась от начала окна больше порога; **случайный лес** — 300 деревьев решений, которые голосуют по 11 числам об окне (перепад, размах, шум, скорость изменения).

**Классы событий** проверены на 134 событиях с известным ответом, подмешанных в реальные записи: длительность, протяжённость и тип — 126 из 126, повторы, периодичность и одновременность — все, пульсация — 6 из 8 (`tools/class_check.py`).

## Запуск

Нужен Python 3.10–3.12 и файлы `1.csv` … `6.csv` в папке `data/` (данные организаторов в репозиторий не входят).

```
pip install -r requirements.txt
python fiberwatch.py --quick --data-dir data --output check_run        # проверка запуска, ~8 мин
python fiberwatch.py --data-dir data --output run_final                # обучение и проверка, ~50 мин на CPU
python fiberwatch.py --detect data/4.csv --model-dir run_final/models --output result_4
```

Результаты обучения — в `run_final/`: `summary.csv` (качество моделей), `events.csv` (события), `figures/` (графики).

Числа отчёта получены с ручными фрагментами (`--annotations`, `--cases-dir`): их места исключаются из обучающего фона, по ним считается слепой тест. Фрагменты в репозиторий не входят, поэтому без них итоговые цифры могут немного отличаться.

Результат применения — папка `result_4/`:

| Файл | Что внутри |
|---|---|
| `events.csv` | уведомления: сообщение оператору простыми словами (`message`), время, участок в метрах, тип, изменение от фона, класс |
| `candidates.csv` | кандидаты: модель видит событие, но изменение от фона меньше 3 °C |
| `forecast.csv` | прогноз: через сколько минут растущее изменение превысит порог |
| `slow_changes.csv` | медленные изменения ≥ 3 °C за 2 часа |
| `moving_heat.csv` | нагревы, движущиеся вдоль волокна: скорость и направление |
| `data_quality_messages.csv`, `quality.json` | разрывы, недостоверные значения, сбои измерения, сдвиги всего волокна |

Порог уведомления по умолчанию 3 °C; другой задаётся ключом `--event-c` (повысить можно без переобучения, понизить — только с ним).

Если в консоли Windows нечитаемые буквы — запускайте `python -X utf8 fiberwatch.py …`.

## Структура

- `fiberwatch.py` — всё решение;
- `REPORT.md` — отчёт: задача, данные, метод, результаты, ограничения;
- `figures/` — рисунки отчёта;
- `tools/` — слепая разметка реальных случаев, расчёт точности, проверка прогноза и классов событий.

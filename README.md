# FiberWatch

Обнаружение температурных событий по данным распределённого волоконного сенсора (DTS).
Решение кейса МГТС «Анализ данных распределённых волоконных сенсоров», хакатон «Телеком будущего».

**Что делает.** Превращает профили температуры вдоль оптоволокна (CSV прибора) в короткий список событий для оператора:

```
15:01:56 UTC — координаты 103,5–114,7 — нагрев +10,3 °C — требуется проверка; причина неизвестна
```

Отдельно выдаёт:

- сообщения о качестве данных — недостоверные значения, разрывы, сбои измерения, сдвиги всего волокна прибором;
- нагревы, движущиеся вдоль волокна, со скоростью и направлением.

**Как.** Свёрточная нейросеть по времени и координате смотрит на 40 минут истории в 9 соседних точках волокна и решает, похоже ли это на событие: настоящий нагрев захватывает соседние точки, а шум и сбой прибора обычно затрагивают одну. Утверждённое правило решает, достаточно ли изменение велико: не меньше 3 °C и от начала окна, и от обычного фона до него. Уведомление — только когда «да» на оба вопроса; иначе — журнал «около порога». Модель учится на окнах настоящих записей, в которые добавлены события с известной амплитудой. Ручная разметка используется только для проверки.

**Насколько хорошо.** Каждую запись проверяет модель, которая этот прибор не видела.

| | CNN время × координата | Случайный лес | Правило «отклонение ≥ порога» |
|---|---:|---:|---:|
| Синтетические события: найдено | 98,7 % | 99,1 % | 92,9 % |
| Синтетические события: верных среди тревог | **95,6 %** | 69,5 % | 78,5 % |
| Тревоги на одноточечных сбоях | **0,9 %** | 98,0 % | 68,1 % |
| Реальная запись, слепая разметка: верных уведомлений | **81 из 82 (98,8 %)** | 84 из 87 (96,6 %) | 77 из 78 (98,7 %) |
| Уведомлений в час на всё волокно (приборы 2, 3, 4, 6) | 0,2–0,7 | 0,2–0,7 | 0,2–0,8 |

На реальной записи с правилом «≥ 3 °C от фона» модели близки: ложные тревоги убирает правило, а нейросеть по соседним точкам отвечает за сбои прибора и краткие выбросы. Четыре раунда слепой разметки (192 случая), ограничения и все версии — в [REPORT.md](REPORT.md).

## Запуск

Нужен Python 3.10–3.12 и файлы организаторов `1.csv` … `6.csv` в папке `data/`.

```
pip install -r requirements.txt
python fiberwatch.py --quick --data-dir data --output check_run        # проверка запуска, ~8 мин
python fiberwatch.py --data-dir data --output run_final                # обучение и проверка, ~45 мин на CPU
python fiberwatch.py --detect data/4.csv --model-dir run_final/models --output result_4
```

Ручная разметка для обучения не нужна. Если она есть, её можно передать как слепой тест: `--annotations annotations.csv --cases-dir cases`.

После полного прогона в `run_final/` появятся:

| Файл | Содержимое |
|---|---|
| `summary.csv` | качество каждой модели на приборе, который она не видела |
| `operator_load.csv` | сколько событий в час получит оператор |
| `events.csv` | найденные события на всех записях |
| `data_quality.csv` | паспорт каждого файла |
| `models/` | итоговые модели |
| `figures/` | графики отчёта |
| `tracks/` | движущиеся нагревы |

В `result_4/` после `--detect`:

- `events.csv` — события;
- `moving_heat.csv` — движущиеся нагревы;
- `near_threshold_journal.csv` — журнал «около порога»: модель видит событие, но изменение от фона меньше 3 °C; без уведомления;
- `slow_changes.csv` — журнал медленных изменений (≥ 3 °C за 2 часа), без уведомления;
- `data_quality_messages.csv` — сообщения о качестве данных.

Если консоль Windows показывает нечитаемые буквы — запускайте `python -X utf8 fiberwatch.py …`.

## Порог уведомления

По умолчанию уведомление — изменение от 3 °C (на шумном приборе — от 4 × шум). Порог сохраняется вместе с моделями, и `--detect` берёт его оттуда.

- **Повысить** (например, до 4 °C) можно без переобучения: меняется только правило.

  ```
  python fiberwatch.py --detect data/4.csv --model-dir run_final/models --output result_4c --event-c 4
  ```

- **Понизить** (например, до 2 °C) — только с переобучением: сеть учили говорить «не событие» на изменениях ниже порога.

  ```
  python fiberwatch.py --data-dir data --output run_2c --event-c 2      # ~45 мин
  python fiberwatch.py --detect data/4.csv --model-dir run_2c/models --output result_2c
  ```

## Структура

| Путь | Что это |
|---|---|
| `fiberwatch.py` | всё решение: чтение и проверка данных, окна, обучение, оценка, события, графики, применение |
| `REPORT.md` | отчёт: задача, данные, метод, результаты, ограничения |
| `tools/check_equivalence.py` | проверки: совпадение с предыдущей версией, оценка шума, отсутствие заглядывания в будущее |
| `tools/compare_v3.py` | сравнение «до/после дообучения» на одних и тех же окнах |
| `tools/build_review.py`, `tools/evaluate_review.py` | слепая разметка реальных случаев и расчёт реальной точности |
| `tools/eval_all_rounds.py`, `tools/compare_real.py`, `tools/measure_study.py` | итоговая оценка по всем раундам, сравнение моделей, выбор способа мерить изменение |
| `history/` | предыдущие версии (v3 → v4 → v4.1 → v5 → v5.1 → v5.2 → v5.3) — для воспроизводимости сравнений |

Исходные данные, разметка и веса моделей в репозиторий не входят.
